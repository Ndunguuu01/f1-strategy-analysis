# Formula 1 Strategy Analysis using CRISP-DM

## Project Overview
This project explores Formula 1 race strategy data using the CRISP-DM methodology. The analysis focuses on tyre degradation, pit stop strategy, lap performance, and machine learning prediction of lap times.

## Objectives
- Analyze tyre strategy trends
- Explore race performance patterns
- Predict lap times using machine learning
- Compare model performance

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Key Insights
- Tyre degradation significantly impacts lap performance
- Pit stop timing affects race outcomes
- Random Forest achieved the best predictive performance

## Methodology
The project follows the CRISP-DM framework:
1. Business Understanding
2. Data Understanding
3. Data Preparation
4. Exploratory Data Analysis
5. Modeling
6. Evaluation
7. Deployment Recommendations
